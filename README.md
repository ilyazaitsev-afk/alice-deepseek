# Алиса + DeepSeek (навык «Дипсик»)

Подключаем Яндекс Станцию к DeepSeek: Алиса распознаёт речь и озвучивает ответы,
а думает DeepSeek. На саму колонку ничего не ставится — это вебхук-навык.

## Как это устроено

```
«Алиса, запусти навык Дипсик» → Яндекс → ваш вебхук (этот код) → DeepSeek API → ответ → Алиса озвучивает
```

Ограничение: навык обязан ответить за **4,5 секунды** (документация Яндекса).
Поэтому код ждёт DeepSeek максимум 4 секунды, а если не успел — просит сказать
«дальше» и отдаёт готовый ответ на следующей реплике. Диалог помнит последние
реплики сессии (память в оперативке сервера).

## Шаг 1. Ключ DeepSeek

1. Зарегистрируйтесь на https://platform.deepseek.com и пополните баланс
   (общение стоит копейки, но API платный).
2. Создайте API-ключ: **API Keys → Create** — получится строка вида `sk-...`.

## Шаг 2. Деплой на Render

1. Выложите папку `alice-deepseek` в свой GitHub-репозиторий.
2. На https://render.com: **New → Web Service** → подключите репозиторий.
3. Настройки:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn main:app --host 0.0.0.0 --port 10000`
   - Environment: `DEEPSEEK_API_KEY` = ваш ключ.
4. После деплоя Render даст URL вида `https://ваш-сервис.onrender.com/`.

> Примечания:
> - Бесплатный тариф Render засыпает при простое: первая фраза за день может
>   сорваться («навык не отвечает»), со второй всё заработает. Можно перейти на
>   платный тариф или пинговать сервис.
> - Альтернатива без серверов — Яндекс Cloud Functions (функция просыпается
>   быстро, есть бесплатная квота): официальная инструкция
>   https://www.yandex.ru/dev/dialogs/alice/doc/ru/deploy-ycloud-function

## Шаг 3. Навык в консоли Яндекса

1. Зайдите на https://dialogs.yandex.ru/developer под тем же аккаунтом,
   к которому привязана Станция (это важно!).
2. **Создать навык → Диалог**.
3. Название — так, как Алиса его распознает: например, **«Дипсик»**.
4. Backend: **Свой бэкенд** → в поле **Webhook URL** вставьте URL от Render.
5. На вкладке **Настройки → Тип доступа** выберите **Приватный** —
   навык будет работать только на ваших устройствах и не требует модерации.
   (Подробнее: https://www.yandex.ru/dev/dialogs/alice/doc/ru/access)
6. **Опубликовать**.

## Шаг 4. Проверка

- В консоли навыка есть вкладка **Тестирование** — проверьте без колонки.
- На Станции скажите: **«Алиса, запусти навык Дипсик»**, затем просто задавайте
  вопросы. Чтобы выйти: «выход».

## Локальный запуск (для отладки)

```bash
export DEEPSEEK_API_KEY=sk-...
uvicorn main:app --host 0.0.0.0 --port 10000
```

Для проброса локального сервера в интернет подойдёт ngrok/cloudflared —
но для постоянной работы со Станцией лучше облако.
